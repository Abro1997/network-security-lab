Network Security Lab

A hands-on cybersecurity project focused on building, monitoring, attacking, and defending virtual networks using Linux.

Project Overview

The goal is to develop practical skills in network engineering, traffic analysis, intrusion detection, and defensive cybersecurity.

Current Progress

Built a virtual network using three Ubuntu machines and VirtualBox.

Configured two separate subnets connected through a Linux router.

Enabled IP forwarding and configured static routes.

Verified inter-network communication using Wireshark.

Analyzed TCP/IP, ARP, ICMP, and packet retransmissions.

Next Milestone: Intrusion Detection System

Deploy Suricata on the Linux router.

Generate controlled suspicious traffic using Nmap.

Create custom intrusion detection rules.

Implement and test firewall protections.

Document security alerts and investigation results.

Tools

Linux · VirtualBox · Wireshark · Python · Nmap · Suricata
